## 云数据库价格由哪几部分组成？

一笔云数据库账单通常包含五块：实例规格、存储空间、备份存储、网络流量，以及可选的安全、审计、跨区容灾等增值项。厂商定价页往往只突出第一块，剩下几块藏在计费文档里，月底出账单时才被发现。

实例规格最好理解：CPU 和内存越大，每小时或每月的单价越高。存储按容量算，类型不同价格也不同。AWS 的通用型 SSD 可以选 20 GiB 到 64 TiB，预调配 IOPS 存储提供 1000 到 256000 IOPS、100 GiB 到 64 TiB 的范围，两者计费逻辑不一样。

备份是第二个容易被低估的项。腾讯云 MySQL 提供最长 1830 天（约五年）的物理冷备，备份数据存多份；保留期越长，占用的存储越多，规划合规留存时间时要把这部分算进去。AWS 的免费套餐包含 20 GB 自动备份存储，超出后的快照按标准费率计费。

流量和跨区操作也会单独计费。AWS 的规则是：同一可用区内 RDS 与 EC2 之间传输免费，多可用区部署的复制流量免费；同区域不同可用区的 EC2 和 RDS 之间传输按标准 EC2 区域数据传输费收取，每 GB 0.01 美元；跨区域快照副本和跨区域自动备份按传输的数据量收费，复制后的快照存储在目标区域还要按当地快照费率计费。

还有一类是版本生命周期费用。AWS 对 RDS for MySQL 和 RDS for PostgreSQL 预置实例的扩展支持按每个 vCPU 每小时计费，Aurora Serverless v2 按 ACU 每小时计费，价格还跟日历日期有关。社区版本停止维护后继续使用，这笔钱会出现在账单上。

## 包年包月、按量计费、Serverless、节省计划，差在哪？

一句话版本：业务稳定且长期跑，包年包月；短期或负载不可预测，按量计费；用量大且能承诺一年，再看节省计划或预留实例；负载间歇且波动剧烈，Serverless 更合适。四种模式解决的是不同问题，混着用比死守一种更省钱。

腾讯云的两种模式分工直接。包年包月购买时一次性支付，适合业务稳定、需要长期使用云资源的团队；按量计费按实际资源使用量结算，适合业务波动大、资源使用临时突发的场景。稳定长期选预付费，波动或临时选后付费。

阿里云的选择更多。除了包年包月、按量付费，还有 Serverless，覆盖 MySQL 和 PostgreSQL，按负载动态匹配资源、实时计费，仅 MySQL 支持 Serverless 转按量付费。弹性型节省计划的操作方式是预付一笔金额，有效期内按 4 折优惠每小时从总金额里扣，扣完或到期为止。存储包和计算包属于预付费资源包，规格越大、时长越长越划算。

## 免费额度和首年优惠，哪些条件容易忽略？

免费额度和首年折扣基本都有附加条件，常见的是注册时间、实例类型、每月可用小时数和配置上限。把免费额度当短期验证工具没问题，当成长期生产方案往往会撞上配置或时长限制。

AWS 的免费套餐在 2025 年 7 月 15 日前后注册的账号规则不同。之前注册的账号可以继续在部分单可用区实例上免费使用 RDS 最多 12 个月，每月最多 750 小时，多个实例的时长累加；同时每月有 20 GB 通用型 SSD（gp2）存储和 20 GB 自动数据库备份存储，免费期 1 年，适用引擎为 MySQL、MariaDB、PostgreSQL 和 SQL Server（仅 Express Edition）。之后注册的账号改为免费计划或付费计划，两种计划都提供 100 美元服务抵扣金，激活 AWS 基础服务最多再拿 100 美元，抵扣金有效期最长 12 个月。AWS GovCloud（美国）区域和中国（北京）区域不提供这项抵扣金。

阿里云的新用户免费试用限定得细：未付费购买过 RDS、且之前未开通过免费试用 RDS PG 的用户，可以免费试用 RDS Supabase 或长期记忆一个月；配置必须是包年包月、PostgreSQL 17 或 18、高可用系列、2 核 4G 通用型、50 GB 存储、时长 1 个月。这不是任意规格的 MySQL 免费一个月。

预留实例和节省计划的“省钱”也有前提。AWS 预留实例要承诺一年或三年，只有用量稳定、能覆盖承诺期时才划算；阿里云弹性型节省计划要先预付，按 4 折每小时抵扣，扣完或到期就结束，适合能预估每小时费用的场景。

## 不同业务场景，计费方式怎么选？

直接给规则：

- 开发测试、临时项目、跑几天就释放：按量计费。别为了折扣买长约，资源不用的时候，折扣省不回来。
- 稳定运行的生产业务，预计一年以上：包年包月。把存储和备份保留期一起算进配置，别只按实例规格估价。规格可以先小后大，腾讯云支持一键升级实例规格，升级过程不影响业务正常访问。
- 负载有明显高峰低谷，暂时说不准：先用按量计费跑一个完整业务周期，拿到真实的 CPU、存储增长数据，再决定要不要转长期。
- 用量大、能承诺一年且追求折扣：对比 AWS 预留实例、数据库节省计划或阿里云节省计划的承诺条件，算清楚承诺期内的总支出，再和按量计费对比。
- 负载间歇、不可预测：阿里云 Serverless 覆盖 MySQL 和 PostgreSQL，按实际用量计费；业务以 MySQL 为主，也可以先用腾讯云按量计费观察一段时间。

还有一个常被忽略的维度：地域。用户在哪，实例就选靠近的地域；不同地域的价格也可能不同，跨地域灾备和快照复制还会产生流量费用。腾讯云 MySQL 支持多可用区部署和跨地域灾备，规划时把灾备流量算进预算。

## 常见问题

### 云数据库一个月到底多少钱？

没有统一答案。同样叫“2 核 4G MySQL”，不同厂商、不同地域、不同存储类型、不同购买时长，价格都不同。准确做法是打开对应厂商的价格计算器，按你的地域、规格、存储和时长填一遍。

### 备份存储要另外付费吗？

看厂商和套餐。AWS 免费套餐包含 20 GB 自动备份存储，超出部分按快照费率计费；腾讯云 MySQL 提供最长 1830 天物理冷备，备份数据存多份，长期保留备份会占用存储资源，规划合规留存时间时应把备份容量纳入估算。比较稳妥的方式是在计费文档或账单明细里确认备份项。

### 跨地域流量怎么收费？

AWS 的规则可以作为参考：同可用区 RDS 与 EC2 之间传输免费，多可用区复制流量免费；同区域跨可用区 EC2 与 RDS 之间按每 GB 0.01 美元收取标准 EC2 区域数据传输费；跨区域快照副本和跨区域自动备份按传输数据量收费，复制后的快照存储在目标区域按当地快照费率计费。其他厂商的具体单价以各自计费文档为准。

### 预留实例一定比按需型便宜吗？

只有用量稳定且能覆盖承诺期时才便宜。AWS 预留实例最多可省 69%，但需要一年或三年的承诺；如果实际用量低于承诺量，省下来的钱可能抵不过闲置成本。

### 腾讯云 MySQL 支持哪些版本和架构？

MySQL 5.6、5.7、8.0，部署架构有单节点、双节点、三节点和云盘版，复制方式支持异步、半同步和强同步。具体选哪种，按业务的一致性和容灾要求来。
